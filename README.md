# Netflix Content Analysis

Exploratory analysis of Netflix's content catalog to identify
trends across content type, release years, countries, genres,
directors, actors, and ratings.

## Tools
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Tableau

## Key Analysis
- Content growth over time
- Movies vs TV Shows across regions
- Genre distribution
- Regional content patterns
- Director productivity
- Actor and director analysis
- Rating/classification distribution
